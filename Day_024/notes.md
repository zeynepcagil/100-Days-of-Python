
## Day 24: Mail Merge Challenge

### Overview

This project automates the creation of personalized letters from a single template. It reads a list of names from one file and a letter template from another, then generates a unique, ready-to-send letter for each person.

### What I Learned

* **File I/O**: I learned how to read and write files in Python. The use of the **`with open()`** statement taught me a safe and efficient way to handle file operations, ensuring resources are properly managed.
* **String Manipulation**: The core of this project was using string methods, particularly **`.replace()`**, to dynamically change content within a text file. This is a fundamental skill for data processing and text automation.
* **Automation with Loops**: I used a **`for`** loop to iterate through each name on the list, demonstrating how to automate a repetitive task. This project showed me the power of Python for scripting everyday, tedious jobs.
